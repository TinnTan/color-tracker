# 红色目标检测

## 功能
实时检测摄像头画面中的红色区域，选择最大的合格轮廓，
显示目标框、中心点和坐标。没有合格目标时显示 No target。

## 本机运行方法
1. 按 Win + Alt + Shift + O 打开项目编辑器。
2. 打开 camera_preview.py，按 F5 运行。
3. 点击摄像头窗口，在英文输入法下按 Q 退出。

注意：此快捷键仅在本机配置生效。


## 检测参数
- lower_red1 = (0, 180, 50)：第一段红色范围下限。
- upper_red1 = (10, 255, 255)：第一段红色范围上限。
- lower_red2 = (170,180, 50)：第二段红色范围下限。
- upper_red2 = (179, 255, 255)：第二段红色范围上限。
- min_area = 1000：最小轮廓面积，单位为平方像素。

## 限制
光线、反光和其他红色区域可能干扰检测。
程序选择最大的合格红色轮廓，不识别物体身份。

## 其他电脑运行方法
需要可用的摄像头及兼容的 Python 环境。
本项目在 Windows、Python 3.14.2 下验证。

在项目目录打开终端，依次执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe camera_preview.py
```

其中安装依赖需要联网下载。

## 录制演示
点击摄像头窗口，在英文输入法下按 R 开始录制。
30 秒后自动保存到项目的 recordings 文件夹。
视频包含目标框和坐标，不含声音。
按 Q 提前退出时，会保存已录制的部分。
